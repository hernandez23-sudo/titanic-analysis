# Análisis Titanic
hernandez23-sudo
## Descripción
Proyecto de análisis exploratorio y preprocesamiento del dataset Titanic de Kaggle. 

## Estructura
- `data/`: Contiene el archivo train.csv 
- `src/analysis.py`: Script principal
- `outputs/resultados/`: Visualizaciones de graficas generadas con las librerias del entorno virtual 

## Instrucciones de ejecución
1. Clonar el repositorio
2. Crear entorno virtual: `python -m venv .venv`
3. Activar: source .venv/bin/activate
4. Instalar dependencias: `pip install -r requirements.txt`
5. Descargar `train.csv` de Kaggle y colocarlo en `data/`
6. Ejecutar: `python src/analysis.py`
